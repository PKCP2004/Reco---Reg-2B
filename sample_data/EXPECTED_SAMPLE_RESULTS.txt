# Sample test cases

Both sample files carry a "Supplier Name" column as the second column, ready for
entry. One register line deliberately leaves it blank so you can see the name
being derived from the GSTIN.

Using the two supplied sample files with tolerance Rs. 1:

| Invoice        | Expected status                       | What it demonstrates                         |
|----------------|---------------------------------------|----------------------------------------------|
| INV-1001       | Matched                               | Clean exact match                            |
| INV-1002       | Value Mismatch                        | IGST short by Rs. 10                         |
| INV-1003       | Matched                               | Intra-state CGST/SGST invoice                |
| INV-1004       | Matched (review date)                 | Invoice date differs by 2 days               |
| INV-1005       | GSTIN Mismatch                        | Wrong GSTIN typed in the register            |
| INV/1006/26-27 | Likely Match - Invoice Format         | Register stores only the serial "1006"       |
| INV-1007       | Tax Head Mismatch (IGST vs CGST/SGST) | Inter-state vs intra-state treatment differs |
| INV-1008       | In 2B Only                            | Filed by supplier, not booked                |
| INV-1009       | Matched                               | Two register lines summed to one 2B invoice  |
| INV-1010       | Matched + period warning              | Supplier filed one month later than booked   |
| OC-2001        | Same PAN - Different GSTIN            | Same supplier PAN, different state           |
| MISC-01        | In 2B Only (with a suggestion)        | Near-miss candidate raised, not auto-matched |
| PURCH-77       | In Register Only                      | The other half of that near miss             |
| REG-ONLY-01    | In Register Only                      | Booked, not filed by supplier                |

Also expected:
- Suggestions sheet: MISC-01 paired with PURCH-77 at a low score, flagged for
  manual confirmation rather than matched.
- Data Quality Checks: INV-1009 repeated invoice number (rate-wise split),
  and a missing supplier name on the INV-1005 register line.
- ITC Statement, Action Plan, Supplier Risk and Aging sheets populated.
